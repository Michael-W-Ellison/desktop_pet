# Quick Start Guide

## For Windows Users

### Method 1: Using Batch Files (Easiest)

1. **First-time setup:**
   - Double-click `setup.bat`
   - Wait for dependencies to install

2. **Run the application:**
   - Double-click `run.bat`
   - An egg will appear on your desktop!

3. **Hatch your pal:**
   - Double-click the egg
   - Meet your new friend!

### Method 2: Manual Installation

1. **Open Command Prompt in this folder**

2. **Install dependencies:**
   ```
   pip install -r requirements.txt
   ```

3. **Run the application:**
   ```
   python desktop_pet.py
   ```

## Basic Controls

- **Double-click egg** → Hatch creature
- **Left-click & drag** → Move pet around
- **Right-click pet** → Menu (Feed, Play, Train, Stats, Exit)
- **System tray icon** → Quick access when pet is hidden

## Your First 5 Minutes

1. **Hatch the egg** (double-click it)
2. **Read the welcome message** to learn about your pet
3. **Right-click → "Play with Ball"** to start playing
4. **Watch your pet** move around and interact
5. **Right-click → "Show Stats"** to see hunger/happiness

## Important Care Tips

⚠️ **Feed your pet regularly!**
- Hunger increases 0.1 per minute
- At 100 hunger, your pet dies
- Right-click → "Feed" to reduce hunger

💡 **Interact often!**
- Pets learn from interactions
- More interaction = happier pet
- Happiness starts falling after 5 minutes without interaction and reaches 0 after an hour
- Each pet has unique preferences

🎓 **Train tricks!**
- Right-click → "Train" → "Learn New Trick" to start a trick, then pick it from "Train" to practice
- Each practice shows the result and the trick's proficiency
- Some personalities refuse to practice more often than others
- Pets need 3 known tricks to evolve into an Elder

## Troubleshooting

**Can't see the pet?**
→ Check system tray, double-click icon to show

**Python not found?**
→ Install Python from https://www.python.org/

**Dependencies failed to install?**
→ Make sure you have internet connection
